# astudio-ai-seo — видимость в ИИ-поиске (GEO / AEO) для Claude Code

[English](README.md) · **Русский**

Автор: **astudio.one** — [astudio.one](https://astudio.one) · Лицензия: MIT · Версия 1.0.0

Один плагин, который учит агента тому, как поиск ChatGPT, Claude, Perplexity, AI Overviews и AI Mode в Google, Copilot и Алиса AI в Яндексе находят, читают и цитируют сайт, и как проверить и исправить сайт под них без мифов. У каждого факта есть дата и источник, поисковые боты не путаются с ботами обучения, а каждое число в отчёте помечено: «измерено», «со слов клиента» или «оценка».

## Что умеет

- Полный аудит видимости в ИИ-поиске по единому шаблону отчёта и план исправлений по приоритетам
- Политика robots.txt по назначению ботов (поиск, обучение, запросы пользователя, ответы Алисы), включая YandexAdditional
- llms.txt и Markdown-версии страниц по спецификации llmstxt.org с честным пояснением, что они дают
- Микроразметка schema.org в JSON-LD, совпадающая со страницей; выведенные расширенные сниппеты помечаются (FAQ отключён 07.05.2026)
- Тексты, которые цитируют: ответ в первой фразе, цифры, источники, цитаты — на русском и английском, по измеренным данным статьи GEO
- Алиса AI: что Яндекс документирует на самом деле, отчёт «Видимость сайта в Алисе AI», требования российского законодательства
- Повторяемые замеры: набор запросов, 3–5 прогонов на запрос, цитирование, упоминание и рекомендация отдельно

## Установка

В Claude Code:

```
/plugin marketplace add whoamnesia/astudio-ai-seo
/plugin install astudio-ai-seo@astudio-ai-seo
```

Перезапустите Claude Code. Навыки появятся в меню `/` как `astudio-ai-seo:astudio-ai-seo` …

Установка на закреплённом коммите (так делает aiocenter.ru): склонируйте репозиторий, перейдите на опубликованный коммит и выполните `/plugin marketplace add ~/.aiocenter/packages/astudio-ai-seo`.

Другие агенты (Cursor, Codex, Gemini CLI): каждый навык — обычный `skills/<name>/SKILL.md` со справочниками; укажите агенту папку или скопируйте её в правила агента.

## Навыки

| Навык | Что делает |
|---|---|
| `astudio-ai-seo` | Главный навык и маршрутизатор: бриф, предпроверка, полный аудит, отчёт, исправления с согласия |
| `ai-crawlers` | robots.txt и метатеги для поисковых ботов ИИ и ботов обучения, матрица «утверждение → бот» |
| `llms-txt` | Проверка и черновик llms.txt, llms-full.txt и Markdown-версий страниц |
| `schema-markup` | JSON-LD по шаблонам страниц, проверка, выведенные типы |
| `citable-content` | Карта вопросов и переписывание страниц с ответом в первой фразе |
| `yandex-alice` | Алиса AI в Поиске, YandexAdditional, отчёт Вебмастера, требования РФ |
| `ai-visibility-tracking` | Набор запросов, повторные прогоны, доля в ответах, ежемесячный отчёт |

## Инструменты

Python 3.9+, только стандартная библиотека. Читают то, что вы им передали, и ничего не записывают, если вы сами не перенаправите вывод.

| Скрипт | Назначение |
|---|---|
| `scripts/robots_audit.py` | Разбор robots.txt для каждого ИИ-бота по назначению, с правилами Яндекса |
| `scripts/llms_txt.py` | Проверка llms.txt по спецификации или черновик из sitemap |
| `scripts/schema_lint.py` | Проверка JSON-LD: разбор, выведенные типы, рекомендуемые поля, совпадение со страницей |
| `scripts/citability.py` | Эвристическая оценка фрагментов на русском и английском с конкретными правками («оценка») |

## Безопасность

- По умолчанию только чтение. Изменения robots.txt, разметки, llms.txt или текстов показываются как дифф и применяются только после «да» человека; старый файл сохраняется.
- Скрипты делают не больше одного GET на переданный адрес, никуда больше ничего не отправляют и ничего не записывают.
- Никакого клоакинга, скрытого текста, поддельных отзывов и массово сгенерированных страниц; никаких обещаний позиций и цитирования.
